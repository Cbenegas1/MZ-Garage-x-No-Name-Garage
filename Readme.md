MZ Garage x No Name Garage 🚗💨

Sitio web oficial y portafolio interactivo para taller mecánico, preparación de alto rendimiento y estética vehicular. Diseñado con una temática oscura y moderna orientada al sector automotriz.
🛠️ Características de la Página

    Diseño Responsivo: Adaptado perfectamente para celulares, tablets y computadoras.
    Preloader Dinámico: Pantalla de bienvenida con animación de carga inicial optimizada por sesión.
    Carrusel de Proyectos: Desplazamiento automático e interactivo para mostrar trabajos y vehículos.
    Reproductor de Música Integrado: Ambiente sonoro personalizado para la experiencia del usuario.
    Enlace Directo a WhatsApp: Botón flotante y de contacto directo para cotizaciones rápidas.
    Redes Sociales Oficiales: Conexión directa a perfiles de Instagram de la administración y del taller.

🚀 Tecnologías Utilizadas

    HTML5 (Estructura semántica)
    CSS3 (Diseño moderno, variables y animaciones)
    JavaScript (ES6+) (Interactividad, control de sesión y carrusel)
    FontAwesome (Iconografía oficial)
